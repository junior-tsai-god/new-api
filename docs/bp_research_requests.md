# BP 补充调研清单（给本地 Codex / CUA）

更新时间：2026-07-07

这份清单用于补齐商业计划书里还不能完全依赖公开网页确认的信息。优先使用官方文档、云控制台、价格计算器、商务邮件或销售报价截图；每条信息都建议保留页面 URL、截图、抓取时间、账号区域和币种。

## 一、价格矩阵

请按下面字段整理成表格：

| 字段 | 说明 |
| --- | --- |
| 供应商 | 阿里云百炼、火山方舟、腾讯混元、百度千帆、DeepSeek、智谱、Kimi、MiniMax、硅基流动等 |
| 模型名称 | 控制台显示的完整模型 ID，不要只写系列名 |
| 地域/站点 | 中国大陆、北美、新加坡、香港、欧洲等；记录控制台实际可选区域 |
| 输入价 | 统一换算为每百万 tokens，保留原币种 |
| 输出价 | 统一换算为每百万 tokens，保留原币种 |
| 缓存价 | cache hit / cache miss 是否不同，分别多少 |
| 批处理价 | Batch、离线推理、异步调用是否有折扣 |
| 免费额度 | 新用户、企业账号、活动额度 |
| QPS/并发 | 默认限制、大客户可谈上限、是否可买专属并发 |
| 备注 | 上下文长度、是否思考模式、视觉/语音/视频是否另计 |

## 二、优先检索任务

1. 阿里云百炼：复核 qwen3.7-max、qwen3-max、qwen-plus、qwen-flash 在中国北京、美国弗吉尼亚、新加坡、香港的价格、可售范围、Batch 50% 折扣、上下文缓存折扣和控制台促销。
2. 火山引擎方舟：抓取文本模型、推理模型、多模态、Embedding、Rerank、图片和视频模型价格；重点确认 Doubao 系列在中国大陆、海外区域的单价、并发、专属资源和大客户框架政策。
3. 腾讯云混元 / TokenHub：确认 Hunyuan-a13b、角色模型、翻译、视觉、Embedding 的最新价；补充预付费资源包、后付费日结、企业折扣、QPS 与迁移政策。
4. 百度千帆：确认 ERNIE 5.0、ERNIE X1、DeepSeek、GLM、Kimi、Qwen 等模型最新价；补充 Token Plan 企业版、批量推理价和专有云选项。
5. DeepSeek 官方：确认 V4-Flash、V4-Pro 的价格、并发、缓存价、废弃模型映射、企业 SLA 和版本锁定可能性。
6. 智谱、Kimi、MiniMax、硅基流动：补齐公开价、企业价、商用授权、速率限制、模型地域和是否支持 OpenAI 兼容接口。

## 三、大客户折扣需要问的问题

对每家供应商尽量拿到这些答案：

| 问题 | 目的 |
| --- | --- |
| 年度承诺消费 10 万、50 万、100 万、500 万人民币分别能谈到什么折扣？ | 判断毛利空间 |
| 是否有预付费 Token 包、资源包、代金券或渠道价？ | 判断采购方式 |
| 是否支持价格保护周期？周期是 1 个月、3 个月还是 1 年？ | 降低调价风险 |
| 是否支持专属 QPS、专属并发池、专线、私有网络？ | 支撑企业 SLA |
| 是否支持企业账期、发票、合同主体、跨境结算？ | 支撑企业销售 |
| 是否允许作为下游 API 中转或聚合服务销售？ | 确认 ToS 风险 |
| 日志、数据留存、训练使用、跨境传输政策是什么？ | 支撑合规路由 |

## 五、优先级

最高优先级：火山方舟文本模型价格、阿里云跨区域可售范围、大客户折扣阶梯、是否允许中转/转售。

第二优先级：智谱、Kimi、MiniMax、硅基流动价格矩阵和 OpenAI 兼容程度。

第三优先级：海外模型供应商与国内模型的同类能力替代关系，包括 Claude、Gemini、OpenAI、OpenRouter 等。
